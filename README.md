# How Machines Work: Machine Garage

An interactive 3D game that teaches how everyday machines work, step by step.

**Open `index.html` in a modern browser to play.** It's a single file. It loads three.js and the Figtree font from public CDNs, so it needs an internet connection.

## Machines

| Machine | Highlights |
| --- | --- |
| Diesel pickup (modelled on a Toyota Hilux 2.8) | Compression ignition, turbo, common rail, DPF and SCR |
| Electric car | Battery, inverter, motor, single-speed gear, regenerative braking |
| Motorcycle | Single-cylinder petrol engine, spark ignition, clutch, chain drive |
| Wind turbine | Blades, pitch and yaw, gearbox, generator, storm shutdown |
| Solar panel (home rooftop) | Cell layers, bypass diodes, inverter, battery, grid export |
| Smartphone | Touch, processor, memory, OLED, cameras, radios, wireless charging |
| Air conditioner (split type) | The refrigeration cycle: evaporator, compressor, condenser, expansion valve |

## Modes

- **Tour:** a 9-step guided walkthrough per machine, with animated energy flows and a quick check at each step. **Play all steps** runs it automatically.
- **Explore:** click any part to learn what it does. Use X-ray and Explode to see inside.
- **Engine Lab** (diesel and motorcycle): a cut-open cylinder. Fire the injector or spark at the right moment in the timing challenge.
- **Part Hunt:** find parts from clues.

**Controls:** right-drag to rotate, left-drag to move, scroll to zoom. Progress and XP are saved in your browser.

The models are simplified and built from code, and the figures are typical values, not the specs of a particular product.
